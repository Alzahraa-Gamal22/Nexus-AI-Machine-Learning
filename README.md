## 🚀 Overview

**Nexus AI** is an interactive Machine Learning platform built with **Python and Streamlit**.

The platform provides a complete Machine Learning workflow, starting from dataset ingestion and preprocessing to exploratory data analysis, feature engineering, model training, evaluation, and prediction.

The goal is to simplify and automate the Machine Learning pipeline through a modern, interactive interface.

## ✨ Features

* 📂 Dataset Upload — CSV and Excel support
* 🔍 Data Exploration and Dataset Profiling
* 🧹 Automated Data Preprocessing
* 🧩 Missing Value Handling
* 🔤 Categorical Encoding
* 📊 Exploratory Data Analysis
* ⚙️ Feature Engineering
* ⚖️ Class Imbalance Handling
* 🤖 Machine Learning Model Training
* 🌲 XGBoost and Scikit-learn Models
* 📈 Model Evaluation and Performance Metrics
* 🔮 Prediction Workflow
* 📊 Interactive Visualizations with Plotly
* 🎨 Modern Streamlit User Interface
